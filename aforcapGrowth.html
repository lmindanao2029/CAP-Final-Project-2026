This is my growth page:

Creating a website was the project that I highly enjoyed the most. While designing and creating my website, I learned how to change font sizes, colors or text, backgrounds, how to attach different links and connect different buttons to each other. I did find it difficult to remember all the start and ending tags such as the body and heading tags. Attaching different links to my website and connecting the different pages to each other was also an obstacle I had to face as at first my links weren’t working. I made sure to use the correct tags such as, src or href. I put in the extra work to make sure that my links did work and go to the correct website, fixing mistaken letters or wrong tags. Knowing what I know now, I would have made my website more detailed, with more facts, colors, images and text.
